# One link is one problem

An activity is a single Multiply or Factor problem, and its link carries nothing else. There are no problem lists, saved activities, starter activities, session limits or end-of-session reports, unlike Morphology Mash. The teacher page makes one link at a time. We chose the simplest thing that works in class: a teacher who wants five problems shares five links. Lists, ordering and reports can be added later if teachers ask for them; until then, don't add them back as a matter of course.
